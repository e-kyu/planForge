# /kickoff — 개발 세션 진입점

## 절차

1. **계약 확인**: `CLAUDE.md`의 설계 원칙 8개(원문: `AGENT-DEV-REQUEST.md` §2.1)를
   확인한다. 이 8개는 계약이며, 위반 시 구현 자체가 오답이다.
2. **진행 상황 파악**: `git log --oneline`과 `git status`로 현재 위치를 판단한다.
3. **계획 제시**: 남은 작업(브라우저 e2e 완주 등)을 기준으로 현재 우선순위의 구현 계획을
   제시한다. 불명확한 점은 진행 전에 사용자에게 확인한다.

## 제약

- 빌더(`backend/reportagent/builders/`)는 로직 변경 금지 — 경로/워크스페이스 주입만
  어댑터로 처리한다.
- LLM 호출은 `openai` SDK 기반 provider 추상화 계층으로만 한다.
- 이식 원문(docs/legacy)은 2026-09 정리로 삭제되었다. 원문이 필요하면 git 이력에서
  복원해 본다 (`git log --follow -- <경로>`).
