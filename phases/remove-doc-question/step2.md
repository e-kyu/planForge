# Step 2: doc-prompt-rewrite — 인터뷰 프롬프트에서 산출 문서 문항 제거 (계약 4세트 마무리)

## 배경 (자기완결 — 외부 대화 참조 금지)

- 이전 step 0(doc-context): `agent.py _turn_context()`가 세션 `doc_slug` → 라벨을
  `### 이번 인터뷰 문서` 블록으로 매턴 주입한다.
- 이전 step 1(plan-doc-guard): `agent.py _write_plan()`에 정합 가드(doc 세션에서
  메타 문서가 주입 라벨 단독이 아니면 ERROR)가 추가됐다.
- 인터뷰 세션은 생성 시 `doc_slug`로 문서가 고정되므로, "이번 인터뷰로 확정할 산출
  문서는 무엇인가요?"를 묻는 절차는 모순이다. 이 step에서 프롬프트에서 제거한다.

**사용자 확정 방향 (이 저장소 기획 결정):**
1. 문서 정체성은 **서술 언급만** — 시작 첫 텍스트에서 "이번 인터뷰는 개발설계서
   단독 인터뷰다"처럼 한 문장 서술하고 바로 가설·질문 진행. 문서 목록을 확정 항목으로
   다루지 않는다.
2. doc_slug 없는 **레거시 세션도 문서 질문은 전면 제거** — 레거시는 제안서 아크로
   진행하고, plan 메타 산출 문서 라인을 쓰지 않는다(파서 default `["제안서"]`).

### 2. `tests/test_interview_api.py` — fake 스크립트·docstring 갱신

- `DESIGN_TURNS` 턴1 텍스트
  `"가설 초안: 산출 문서는 개발설계서 단독 — 설계 결정 설문을 진행한다."` →

  동일한 서술 언급형으로 바꾸고 세션 생성에 `json={"doc_slug": "proposal"}`.
