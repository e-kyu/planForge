# 레이아웃 레퍼런스 (16:9, 13.333 × 7.5 in)

`SKILL.md`의 규칙을 좌표 수준으로 정밀화한 참고 문서. 모호할 때만 본다.

## 공통 좌표

- 슬라이드 제목: (0.6, 0.4), 폭 12.1, 높이 0.8, 28pt 굵게 TEXT
- 제목 아래 구분선: (0.6, 1.2) → (12.7, 1.2), LINE 1pt
- 본문 영역: y 1.5 ~ 6.9, 좌우 0.6 여백
- 슬라이드 번호: (12.3, 7.0), 10pt TEXT_SUB — 본문형 유형(toc/two-col/table/chart/arch)에만 표기 (cover·closing은 없음)

## 유형별

### cover
- 배경 NAVY 전체 사각형
- 사명: (0.7, 0.5), 14pt LIGHT_BLUE
- 제목: (0.7, 2.6), 40pt 흰색 굵게, 좌측정렬
- 부제: (0.7, 3.9), 18pt LIGHT_BLUE
- 날짜·부서: (0.7, 6.5), 12pt LIGHT_BLUE

### toc
- 각 항목: 번호(24pt BLUE 굵게) + 본문(20pt TEXT), 세로 간격 1.2in, 시작 y 2.2

### two-col
- 좌 박스: (0.6, 1.5) 크기 5.9 × 5.2, BG_SOFT, 모서리 없음
- 우 박스: (6.8, 1.5) 크기 5.9 × 5.2
- 박스 내 소제목 16pt BLUE 굵게, 불릿 13pt (label 굵게 + body 일반)

### table
- 표 시작 (0.6, 1.5), 폭 12.1, 행 높이 0.5 (전체 높이 상한 5.2)
- 헤더: NAVY 배경, 흰색 13pt 굵게 / 본문 행: 12pt, 짝수 행 BG_SOFT
- note 캡션: (0.8, 6.6), 10pt TEXT_SUB (note가 있을 때만)

### chart
- 차트 (0.8, 1.6) 크기 11.7 × 4.6, 세로 막대 기본
- 출처 캡션: (0.8, 6.6), 10pt TEXT_SUB

### arch
- 밴드 영역: x 0.6~12.7, y 1.5~6.7. 밴드높이 = min(1.05, (5.2 − 0.18 × (계층수 − 1)) / 계층수), 밴드 간 세로 간격 0.18, 상단 정렬
- 좌측 계층명 박스: (0.6, y) 크기 2.0 × 밴드높이, BG_SOFT, 계층명 13pt BLUE 굵게 중앙정렬
- 구성요소 박스: x 2.75부터 폭 9.95를 아이템 수만큼 균등 분할 (박스 간격 0.12), 높이 밴드높이 − 0.2 (y + 0.1에 배치), 흰 배경 + LINE 1pt 테두리, 라벨 12pt TEXT 중앙정렬
- 계층당 구성요소 최대 6개, 계층 최대 6개 (초과 시 build_ppt.py가 오류)
- note 캡션: (0.8, 6.6), 10pt TEXT_SUB (note가 있을 때만)

### closing
- 배경 NAVY, 제목 (0.7, 1.8) 32pt 흰색
- 요약 불릿 (0.7, 3.2) 16pt 흰색
- note(요청 사항): (0.7, 5.8) 14pt LIGHT_BLUE
