# PRD: PlanForge

## 목표

"인터뷰에 답하면 제안서·개발설계서가 PPT·문서로 나온다"를 브라우저에서, Claude Code 없이
실현하는 기획 문서 생성 웹 서비스. 브라우저에서 에이전트와 인터뷰를 진행하면 확정 팩트가
쌓이고, 그 내용으로 기획서(plan)가 만들어지며, 승인 한 번으로 PPTX·MD·HTML·DOCX 산출물이
결정론 빌더에 의해 채번 생성된다.

## 사용자

- 사내 팀 단위 1~10명 — 기획 문서(제안서·개발설계서)를 작성해야 하는 구성원(비개발자 포함).
- 사내망 신뢰 전제 — 인증·로그인은 생략(추후 확장 항목). 클라우드 미사용, 사내 서버
  Docker Compose 배포(ollama/openai/azure를 OpenAI 호환 프로토콜로 소화).
- 기원: 조달청 인증서 배포 업무 등에서 수작업으로 겪던 문서 작성 부담을 에이전트 인터뷰로
  대체하는 것.

## 핵심 기능

1. **프로젝트 생성** — 제목·슬러그로 프로젝트를 만들고 워크스페이스(work/output/docs/assets)를
   자동 생성한다.
2. **소스 등록** — 기존 기획자료(.md .txt .json .csv, 2MB 이하, UTF-8)를 업로드한다.
   인터뷰가 이 자료를 읽고 시작한다. 글로벌 소스(`sources/`)는 모든 프로젝트가 공유한다.
3. **인터뷰** — 에이전트가 소스·기존 팩트로 예상 뼈대(가설)를 먼저 제시하고 틀린 부분만 질문한다.
   라운드당 최대 4문항, (모름) 추천 칩으로 넘길 시 추측 없이 `(미확정)` 팩트로 적립.
   라운드 종료마다 팩트 확인 게이트 + 핵심 메시지 3개 승인(서아 아크: 문제 정의→해법→기대효과).
4. **plan 작성·승인** — 인터뷰 결과 plan(마크다운)을 뷰어/에디터/diff로 확인하고 승인해야만
   다음 단계로 간다.
5. **파생물 생성** — 대상 문서(제안서/개발설계서)를 골라 생성하면 LLM이 plan→slides.json/
   report.json으로 변환하고 결론 빌더가 `output/<문서 제목>_vNN.pptx` 등을 채번 생성한다
   (절대 덮어쓰기 금지). 수치 위반이 남으면 검수까지 자동 실행(결정 17).
6. **검수** — 결론 검수(수치 무결성·문서 태그·구조·세대 대응) + LLM 내용 검수가 🔴/🟡/⚪
   등급 리포트를 만든다. 발견사항은 plan_revise job으로 plan에 반영(새 세대)한 뒤 재승인·
   재생성한다. 수정은 **plan 수정 → 재승인 → 재생성(버전 +1)**만이 유일한 경로다.
7. **팩트 관리** — 팩트 저장소(패널·단건 수정), 인터뷰가 길어지면 팩트 압축(미리보기→적용).

## MVP 제외 사항

- 인증·로그인 / 프로젝트별 접근 제어(데이터 모델 user 필드 여지만 UI 미구현)
- 클라우드 배포 — 사내 서버 Docker Compose로 고정
- 멀티 워커 — 빌더 스레드 안전성 전제로 단일 워커 직렬만(BEGIN IMMEDIATE 재설계 전 도입 금지)
- 소프트 삭제 — 물리 삭제 + 프로젝트 영구 삭제(되돌릴 수 없음)
- anthropic SDK 등 OpenAI 호환 외 LLM 프로토콜
